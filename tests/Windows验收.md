# v0.5.14-BAT Windows 验收

先运行 `tests/Run-Windows.ps1`，再用自有测试窗口验收原生交互。云端的 97 项检查使用模拟鼠标，不代替以下实机行为。

## V0.5.14 可见自删除验收

1. 不勾选隐藏、勾选末尾自删除，重新生成只含等待的 BAT：运行期间黑框可见，结束时删除当前 BAT，不启动隐藏 PowerShell 清理进程。分别测试两引擎和管理员开关。
2. Windows 自动用例仅执行从实际生成 BAT 提取的清理块，使用临时无动作 BAT，验证自删除及退出码 0/7，文件名包含中文、空格、单引号、&、%、! 和括号；另持有文件锁验证删除失败保留文件、输出警告并保持退出码。云端没有执行原生 cmd 用例。
3. 不勾选删除时文件保留并暂停；删除权限受限时显示警告，不误报已删除，退出码仍来自原流程。提权取消/失败不得误删文件。
4. 鼠标、按键、中文输入、条件重试和随机等待照常回归；若手动勾选隐藏模式，仍是原有隐藏实现，不能期待本次可见清理修改影响它。
5. 在火绒开启的测试机上重新生成和验收，记录日志/版本；不以关闭防护或加排除项作为修复。没有保证所有安全提示都会消失。

## V0.5.13 BAT 启动兼容性验收

1. 原有设置与默认勾选不变，全部动作可编辑/复制/保存。导出仍只有一个 BAT；单独复制 BAT 到目标机可运行，不需要工具箱或旁边的 PS1。
2. 普通用户勾选管理员后，正常显示 Windows UAC；同意后在管理员窗口执行一次，原窗口结束。取消/失败时提示并停止；已是管理员时不重复申请。使用中文、空格、单引号、&、% 的目录/文件名分别测试文件关联启动及工作目录。
3. 两引擎分别验证鼠标物理坐标、按键、中文输入、窗口激活、条件和随机等待；显示/隐藏与自删除选项都保留，核对结果和选项一致。隐藏模式本来不输出可见诊断信息。
4. 只含等待且关闭诊断时不生成输入桥接/COM；含输入或诊断时保留所需组件，窗口激活可正常创建 COM。
5. 启动段不再使用 EncodedCommand；主体仍为 Base64/ScriptBlock。Windows 脚本解析所有启动段，UAC 三分支仅用替身模拟，不能替代第 2 项的真实 UAC 验收。
6. 保持火绒开启，重新生成最小 BAT 测试并记录日志、版本、哈希及选项。当前不承诺告警消失；若仍拦截提交官方误报渠道。详见 [静态审查记录](../docs/bat-review-v0513.md)。
