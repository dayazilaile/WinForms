## V0.5.19 随机 IPv4 实机验收（待执行）

1. 在可恢复的测试网卡上填准确名称、地址段/CIDR 和网关，保留火绒运行。核对普通用户正常 UAC 与管理员直接运行；不勾选提权又无权限时应明确失败。
2. 分别选择“继续流程”和“结束脚本”，在后面放一个无破坏性动作；后者不得执行后续步骤，即使随机 IP 在嵌套分支/重试内；勾选/取消自删除分别核对收尾。
3. 用已知占用地址测试 ARP 预查/Duplicate 换号，不能仅用 Ping；成功候选设置后应观察完整 10 秒并核对实际 IP、前缀、静态模式与网关。未响应/关机设备无法保证检测。
4. 核对 1–99、101–253 候选限制及排除项，包括网关在候选范围内、/20 跨第三段网关和 /25 小子网；不得反复使用失败候选。
5. 断网、DAD 关闭、多 IPv4/多默认路由时应在修改前拒绝；池耗尽、设置错误时停止后续动作并尝试恢复原 DHCP/单静态配置。分别验证恢复成功、恢复失败提示；DHCP 可能重新分配租约。操作可能中断远程连接，应具备本地恢复方法。
6. 脚本不主动写 DNS 或新增报告/备份文件。测试生成的 random-ip-fixture.ps1 用模拟网络调用和加速时钟验证，不能替代上述真实网络验收。

## V0.5.15 两分钟超时验收

1. 新增等待窗口，目标填唯一不存在标题，超时留空：约 120 秒后停止并返回失败；勾选末尾删除时自动清理，后续鼠标/程序动作不得执行。不附加 15 秒等待；窗口在期限内出现则正常继续。
2. 参数 2 明确填 90 等较短值时保留该值；0、121、非整数或空窗口关键词不得生成。旧的 15 秒设置需改为 120。不要把时限误认为整个流程的总时长。
3. 文件/网络/Build 条件正常成立和不成立均走对应分支。求值异常/不明确/超过 120 秒时不进入任一分支，外层重试也不再重试；网络无 Ping 回应仍允许作为明确否。
4. 不勾选末尾删除时保留 BAT 并暂停；勾选时保留 V0.5.14 当前可见窗口清理。UAC 取消不执行动作，文件锁/权限限制不伪报清理成功。
5. `tests/Run-TimeoutFixtures.ps1` 只执行无破坏性的生成用例，超时缩短为 1 秒并替换窗口枚举；核对真假结果、判断报错/模糊结果、超时、否则分支及失败退出。Linux PowerShell 7.4.13 已运行，Windows PowerShell 5.1 和真实 cmd 清理仍须运行 `Run-Windows.ps1` 验证。

## V0.5.14 可见自删除验收

1. 不勾选隐藏、勾选末尾自删除，重新生成只含等待的 BAT：运行期间黑框可见，结束时删除当前 BAT，不启动隐藏 PowerShell 清理进程。分别测试两引擎和管理员开关。
2. Windows 自动用例仅执行从实际生成 BAT 提取的清理块，使用临时无动作 BAT，验证自删除及退出码 0/7，文件名包含中文、空格、单引号、&、%、! 和括号；另持有文件锁验证删除失败保留文件、输出警告并保持退出码。云端没有执行原生 cmd 用例。
3. 不勾选删除时文件保留并暂停；删除权限受限时显示警告，不误报已删除，退出码仍来自原流程。提权取消/失败不得误删文件。
4. 鼠标、按键、中文输入、条件重试和随机等待照常回归；若手动勾选隐藏模式，仍是原有隐藏实现，不能期待本次可见清理修改影响它。
5. 在火绒开启的测试机上重新生成和验收，记录日志/版本；不以关闭防护或加排除项作为修复。没有保证所有安全提示都会消失。

## V0.5.13 BAT 启动兼容性验收

1. 原有设置与默认勾选不变，全部动作可编辑/复制/保存。导出仍只有一个 BAT；单独复制 BAT 到目标机可运行，不需要工具箱或旁边的 PS1。
2. 普通用户勾选管理员后，正常显示 Windows UAC；同意后在管理员窗口执行一次，原窗口结束。取消/失败时提示并停止；已是管理员时不重复申请。使用中文、空格、单引号、&、% 的目录/文件名分别测试文件关联启动及工作目录。
3. 两引擎分别验证鼠标物理坐标、按键、中文输入、窗口激活、条件和随机等待；显示/隐藏与自删除选项都保留，核对结果和选项一致。隐藏模式本来不输出可见诊断信息。
4. 只含等待且关闭诊断时不生成输入桥接/COM；含输入或诊断时保留所需组件，窗口激活可正常创建 COM。
5. 启动段不再使用 EncodedCommand；主体仍为 Base64/ScriptBlock。Windows 脚本解析所有启动段，UAC 三分支仅用替身模拟，不能替代第 2 项的真实 UAC 验收。
