# V0.5.0 Windows 新增验收

先执行 `tests/Run-Windows.ps1`；以下为真实设备验收步骤，不代表云端已验证。

1. 导航：默认仅展开一个分类；点击分类文字和 +/- 均能展开收起。搜索 DNS、WiFi、打印机；回车打开首项，无结果没有可点击假入口。清空后恢复展开状态，重启后恢复最后页面。检查 125%、150%、200% DPI 与高对比度下可读性。
2. TCP 扫描：用本机测试监听端口验证“开放”，关闭端口验证“拒绝”，不可达地址验证超时；CIDR/端口数量/并发边界应拒绝。开始后停止或关闭窗口，任务停止后可导出已完成结果。不要把未响应当作设备离线。
3. 主机发现：使用已知的局域网 /24 与 /32，核对响应主机；禁用 ICMP 的设备若有 TCP 响应仍应显示。多网卡下确认用户输入的网段符合实际网络。
4. 路由/MAC/DHCP：与 `ipconfig /all`、`route print`、`arp -a` 对照，确认读取不改变配置。DHCP 服务器字段缺失不等于没有其他服务器。
5. DNS/TCP/HTTP：测试已知服务、404/401/405、302 跳转、超时与错误证书；不能自动跳转，不能忽略证书错误。停止应终止当前请求/命令。
6. Wi-Fi：核对接口、BSSID、信号、信道；没有网卡或位置权限时显示实际系统错误。普通配置报告不得出现密码。单独确认后按准确配置名显示密码，取消确认不读取；关闭敏感窗口后普通窗口仍不含密码，导出不得带入敏感窗口内容。
7. 摄像头：选择相同 VLAN 网卡，已开启 ONVIF 发现的设备应能被发现；不支持设备可能无结果。错误网卡、设备无响应、防火墙限制均不能显示虚构设备。停止/关闭窗口后不得持续占用 UDP 套接字。声明地址仅作为文本，不能自动登录、打开或播放。
8. 回归：执行以下 V0.4.5 的原功能验收，尤其验证命令执行修改后的系统检查、SMB 诊断与取消逻辑。新代码未加入抓包、主动 DHCP 服务器发现、会话压力测试或 AI 接口。

## V0.4.5 原功能验收

建议在 Windows 10 和 Windows 11 各测试一次。先执行 `tests/Run-Windows.ps1`，再检查下列真实系统功能。以下为待执行用例，不代表云端已经验证。

1. 配置对比：分别导出两台电脑报告，比较已知不同的 DNS/服务状态；同份报告比较应无差异。取消文件选择或导入无效文件应保留窗口可用。
2. 打印机：核对默认打印机、驱动及端口与系统设置一致。对测试打印机提交两个任务并确认取消，仅清理该队列。分别测试可达端口和关闭端口，TCP 测试不能产生打印任务。
3. 网络：对已允许 ICMP 的网关采样，核对 CSV 行数、时间和汇总；检测中断开网络再恢复，记录应出现对应状态。点击停止，等待当前探测结束，仍可导出。无 ICMP 响应不能判定为应用缺陷或断网。
4. 软件：导出完整登记清单，导入包含已装、未装、低版本以及非标准版本的软件要求；核对四类结果。覆盖 x86/x64 程序与当前账户安装的软件。
5. BAT：验证文件存在/不存在的两条分支、网络可达/不可达、Build 区间及嵌套。使用返回 0 和非零的测试程序检查等待、超时、重试次数；缺少结束、重复否则和非法重试参数应被拒绝。
6. U 盘：用没有可执行代码的文本文件命名为 `资料.pdf.exe` 和 `autorun.inf`，再放正常文档及指向记事本的快捷方式。扫描应显示依据且不能执行文件、修改内容或属性；导出报告后与原文件哈希/属性核对。拔出 U 盘时应报告读取失败而非卡死或安全结论。
7. Defender：对照 Windows 安全中心记录，核对名称、盘符和时间。没有历史应显示无法据此判断安全；关闭 Defender 或非管理员时应明确接口/权限错误。
8. 自动播放：记录原策略，关闭后核对 `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer\NoDriveTypeAutoRun`，重新登录验证；还原应恢复首次备份原值或原先不存在状态。
9. USB 写保护：同一管理员账户记录原策略并开启；重新插拔测试盘，尝试新建测试文件，确认设备实际拒绝写入。还原策略再插拔应恢复原先行为。若组织策略/设备驱动不支持，不能把注册表写入成功当作实际防护成功。
10. 窗口：检测进行中点关闭，应先请求停止，不应留后台扫描；检查小屏幕和 150% 缩放下按钮可滚动、结果可导出。

验收不要求导入真实恶意样本，不要在生产共享或重要资料上做取消打印/写保护等有影响的测试。
