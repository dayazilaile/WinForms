# v0.5.10-BAT Windows 验收

先运行 `tests/Run-Windows.ps1`，再用自有测试窗口验收原生交互。云端的 59 项检查使用模拟鼠标，不代替以下实机行为。

1. 把 BatAutomation.exe 单独复制到新建空文件夹启动。应直接显示 BAT 编辑器，没有工具箱目录、硬件查询或 Database 依赖；添加、复制、拖动、编辑和清空动作可正常操作。
2. 打开原工具箱 v0.5.10 保存的流程，核对动作、引擎、延时、UAC、诊断和自删除选项；保存后回到原工具箱重开，内容保持。新建工作流保存及取消文件选择不误执行动作。
3. 文件/网络/系统条件显示两栏，可添加多个动作或一边留空；保存自动补齐分支，取消不改原流程。嵌套、复制和拖动保留完整结构；重试和清理/格式化限制保持。
4. 两种 BAT 引擎先用等待、测试窗口和无敏感内容的文字验证；单独把生成的 BAT 放到目标测试机，不安装编辑器也能运行。检查 UAC/隐藏/诊断/末尾自删除与选项一致。
5. 在 100%/125%/150%/200% 缩放及不同缩放的多屏下抓取物理坐标，再测试移动核对同一点；切换动作、关闭窗口取消倒计时，失败不写逻辑坐标。
6. 键盘录入仅对捕获窗口响应；窗口选择包括最小化窗口。目标窗口权限、焦点和 UAC 安全桌面限制应按实际结果提示，不宣称绕过输入限制。
7. 1000×670 最小主窗口下检查工具栏、选项、列表、预览与两栏条件弹窗；流程中的文件/网络修改动作只在自有测试环境按原有确认和权限要求验收。
