## V0.5.17 下发清理脚本验收

1. 从正确标准机建立完整标准，导出脚本时分别选择确认/自动，取消不得生成或执行；单 BAT 中规则应为保存的标准，不含教师机卸载路径。标准变更后重新导出；空标准/导出失败不破坏原 BAT。
2. 仅在可恢复的测试机安装一个可丢弃测试软件，确认模式开始前只确认一次；取消不能执行卸载。确认后按该软件卸载向导操作，结束仅弹结果，不产生本工具的 TXT/CSV/日志。
3. 自动模式有 QuietUninstallString 时用原登记参数；无静默命令时跳过，不猜开关。MSI 必须使用明确产品代码和系统 msiexec，自动加 /qn /norestart；未知代码、脚本执行器、歧义路径不得执行。
4. 在普通学生账户执行：用户级卸载在原账户进行；全机软件正常申请 UAC，管理员阶段只读取 HKLM，不误处理另一个管理员 HKCU，也不重复确认/弹完成。取消 UAC、重启请求或超时不得误报完成。
5. 标准内软件保留；火绒等安全/教学管理/驱动/基础运行组件和 NoRemove/SystemComponent/更新项不强制卸载。登记改变须重新核对；读取不完整或空标准停止清理。其他用户和便携/商店应用不保证覆盖。
6. 退出码 0 但登记仍在时必须提示未全部完成；已清理登记仍不等于清除所有残留。单个卸载器十分钟未结束时停止本轮、不强杀。需要重启提示后核对，不由脚本主动重启。
7. 使用真实桌面会话以看到弹窗；服务/Session 0 不保证显示。核对脚本不写结果报告、脚本日志、临时 PS1 或自删除清理任务。Windows 和原卸载器自身日志不应被关闭或声称已禁止。
8. 云端 444 项检查和 PowerShell 7 内核模拟通过，没有执行真实卸载、UAC 或火绒验证。Windows 运行入口会解析并调用软件清理模拟用例，模拟替换登记、进程和弹窗，不能代替以上实机验收。

## V0.5.16 标准软件清单验收

1. 未保存标准时全部已安装项显示未建立标准，多出视图不能误列全部软件；损坏/无法读取标准时显示原因。旧关键词文件从“版本检查”导入，不得误当标准清单。
2. 在正确电脑上从本机建立草稿：不受搜索/显示范围影响；勾选、修改名称/发布者、添加/删除行后保存，取消不能修改原标准。至少保留一项，空名称/制表符/换行等无效内容须拒绝。保存失败留窗提示，原文件保留。
3. 新建标准后自动显示多出软件；同名大小写/首尾空格不产生差异，发布者可选，版本列升级不应变成多出；相似名称和发布者不符应列出。同名不同登记记录不能合并后错误卸载另一项。
4. 多出表格搜索、排序后右键自有测试软件：确认窗口名称/路径必须与点击行一致。取消不启动任何卸载；确认后进入该软件正常向导，不直接删目录/注册表，不假报成功；完成后刷新。
5. 缺少条目无卸载入口；NoRemove/无有效卸载路径项目保持禁用或 Windows 设置回退。右键空白处不得继续使用上一行执行卸载。
6. 导出标准到另一台测试机，导入后立刻重算多出/缺少；重新进入或重启后恢复保存的标准。当前清单保存于当前用户 AppData，更新/重新编译不覆盖；导出 CSV 与标准文件用途不同。
7. 注册表读取部分失败时，缺少项目显示未找到/待核对，并保留失败提示；便携软件、商店应用或其他用户软件不属于完整覆盖承诺。窄窗口/125%/150%/200% DPI 检查工具栏、标准编辑器和全宽表格。
8. 云端 432 项检查中，新增标准检查 20 项、界面 19 项；使用模拟卸载计划/确认/启动器，没有执行真实卸载。Windows 实际卸载、权限及原生对话框仍需验收。

## V0.5.13 BAT 启动兼容性验收

1. 原有设置与默认勾选不变，全部动作可编辑/复制/保存。导出仍只有一个 BAT；单独复制 BAT 到目标机可运行，不需要工具箱或旁边的 PS1。
2. 普通用户勾选管理员后，正常显示 Windows UAC；同意后在管理员窗口执行一次，原窗口结束。取消/失败时提示并停止；已是管理员时不重复申请。使用中文、空格、单引号、&、% 的目录/文件名分别测试文件关联启动及工作目录。
3. 两引擎分别验证鼠标物理坐标、按键、中文输入、窗口激活、条件和随机等待；显示/隐藏与自删除选项都保留，核对结果和选项一致。隐藏模式本来不输出可见诊断信息。
4. 只含等待且关闭诊断时不生成输入桥接/COM；含输入或诊断时保留所需组件，窗口激活可正常创建 COM。
5. 启动段不再使用 EncodedCommand；主体仍为 Base64/ScriptBlock。Windows 脚本解析所有启动段，UAC 三分支仅用替身模拟，不能替代第 2 项的真实 UAC 验收。
6. 保持火绒开启，重新生成最小 BAT 测试并记录日志、版本、哈希及选项。当前不承诺告警消失；若仍拦截提交官方误报渠道。详见 [静态审查记录](../docs/bat-review-v0513.md)。

1. 导航：确认 7 个分类、30 个入口，安全维护功能均在系统与硬件下。即使旧导航文件保存其他页面，每次启动也必须先显示系统概览。
2. 直接页面：点击端口扫描、主机发现、路由/MAC、Wi-Fi 分析，不应出现中间“打开”按钮或弹窗。路由、Wi-Fi 自动读取且可刷新；主机页直接显示输入与 Ping 表格。
3. 端口：默认预设应有 125 个唯一常用 TCP 端口，也可自定义。用本机自有监听端口验证开放，关闭后验证拒绝；服务名只是参考，不能按端口推断实际软件。确认 UDP 不在此检测范围。
4. 纯 Ping：对允许与禁止 ICMP 的测试主机检测，结果应只取决于 Ping，不能因为 TCP 80/445/3389 可连接就显示“有响应”。未响应不等于离线。测试开始/停止及快速切换页面。
5. 路由/MAC：对照系统实际网卡、IP、MAC、IPv4/IPv6 路由、邻居缓存；网卡/路由/邻居应分表展示。读取失败需显示原因，不得把失败当作空结果成功。
6. Wi-Fi：对照真实接口与热点，检查接口 MAC 和 BSSID 不混用，频率单位 MHz，基本速率/支持速率/当前收发速率含义独立。2.4/5/6GHz 信道显示应符合系统返回频率；没有基本速率标记、未连接或未提供频率时显示未知，不猜测。附近列表为系统缓存。
7. 权限与服务：关闭 WLAN 服务、撤销位置权限或无无线网卡时，应给出明确状态；重新允许后可刷新。确认不自动连接热点，不修改无线配置。
8. 布局与生命周期：1000×670、正常尺寸、125%/150%/200% DPI 检查关键列、按钮、表格滚动条与状态提示；普通菜单可折叠。扫描/读取时快速切页或关闭，不能出现已释放控件异常或在新页填入旧结果。CSV 应跟随可见列顺序，并将潜在公式作为文本。
9. Wi-Fi 排版测试数据只由测试程序注入，正常程序不能出现样例 SSID/MAC。实机缺少数据时必须显示实际空结果/错误，不能以截图样例填充。

## V0.5.9 U 盘、路由列宽与鼠标验收

1. 插入自有 NTFS 和 exFAT/FAT32 测试 U 盘，列表应显示盘符及格式。选择非 NTFS 时权限设置/恢复禁用，并提示可使用本机 USB 写保护、仅影响当前电脑；不会请求管理员、递归改权限或格式化。切换 NTFS 后可用。

3. 在测试电脑核对原有本机 USB 写保护：需重新插拔，可能影响其他 USB 存储，按原备份恢复策略。到其他电脑不会自动受保护，不验证为跨电脑保护。
4. 路由与 MAC 对照用户截图：网卡、状态、MAC、IPv4、掩码、IPv6、网关间距收紧，网关比原来更靠前；状态表头横排，MAC/IP 不丢失。窄窗口可横向滚动，长值悬停可查，IPv6 模式网关/DNS 仍留足宽度。
5. 在 100%/125%/150%/200% 缩放下添加“移动鼠标”，点击捕获后把光标放到可识别目标，倒计时结束填 X/Y；完成后不抢焦点。点击“3 秒后测试移动”，核对回到同一点。参数为物理像素，不按缩放比例乘除。

5. BAT：验证文件存在/不存在的两条分支、网络可达/不可达、Build 区间及嵌套。使用返回 0 和非零的测试程序检查等待、超时、重试次数；缺少结束、重复否则和非法重试参数应被拒绝。
6. U 盘：用没有可执行代码的文本文件命名为 `资料.pdf.exe` 和 `autorun.inf`，再放正常文档及指向记事本的快捷方式。扫描应显示依据且不能执行文件、修改内容或属性；导出报告后与原文件哈希/属性核对。拔出 U 盘时应报告读取失败而非卡死或安全结论。
7. Defender：对照 Windows 安全中心记录，核对名称、盘符和时间。没有历史应显示无法据此判断安全；关闭 Defender 或非管理员时应明确接口/权限错误。
8. 自动播放：记录原策略，关闭后核对 `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer\NoDriveTypeAutoRun`，重新登录验证；还原应恢复首次备份原值或原先不存在状态。
9. USB 写保护：同一管理员账户记录原策略并开启；重新插拔测试盘，尝试新建测试文件，确认设备实际拒绝写入。还原策略再插拔应恢复原先行为。若组织策略/设备驱动不支持，不能把注册表写入成功当作实际防护成功。
10. 窗口：检测进行中点关闭，应先请求停止，不应留后台扫描；检查小屏幕和 150% 缩放下按钮可滚动、结果可导出。
11. NTFS U 盘权限：使用空白测试 U 盘，先存入文件，再选择“普通用户只读”。在另一台 Windows 电脑以普通用户尝试读取、新建、修改和删除；用管理员账户核对仍可维护。回原电脑恢复权限，再核对原账户权限。另用 exFAT 测试盘确认操作被拒绝且不格式化。
12. 指定文件夹权限：只选无重要数据的测试文件夹，运行“取得指定文件夹权限”，核对 Administrators 所有权和完全控制，以及界面显示的失败项。
13. BAT 清空回收站：仅在测试账户中放入可丢弃文件，生成含该动作的 BAT，执行后核对当前运行账户在各盘的回收站。使用其他管理员账户提权时核对目标账户；不要在日常账户上试运行。

验收不要求导入真实恶意样本，不要在生产共享或重要资料上做取消打印/写保护等有影响的测试。
