# V0.5.9 Windows 验收

以下为真实设备待执行用例。先运行 `tests/Run-Windows.ps1`，再做实机检查；Linux 界面截图不能代替 Windows WLAN/权限/DPI 验收。

1. 导航：确认 7 个分类、30 个入口，安全维护功能均在系统与硬件下。即使旧导航文件保存其他页面，每次启动也必须先显示系统概览。
2. 直接页面：点击端口扫描、主机发现、路由/MAC、Wi-Fi 分析，不应出现中间“打开”按钮或弹窗。路由、Wi-Fi 自动读取且可刷新；主机页直接显示输入与 Ping 表格。
3. 端口：默认预设应有 125 个唯一常用 TCP 端口，也可自定义。用本机自有监听端口验证开放，关闭后验证拒绝；服务名只是参考，不能按端口推断实际软件。确认 UDP 不在此检测范围。
4. 纯 Ping：对允许与禁止 ICMP 的测试主机检测，结果应只取决于 Ping，不能因为 TCP 80/445/3389 可连接就显示“有响应”。未响应不等于离线。测试开始/停止及快速切换页面。
5. 路由/MAC：对照系统实际网卡、IP、MAC、IPv4/IPv6 路由、邻居缓存；网卡/路由/邻居应分表展示。读取失败需显示原因，不得把失败当作空结果成功。
6. Wi-Fi：对照真实接口与热点，检查接口 MAC 和 BSSID 不混用，频率单位 MHz，基本速率/支持速率/当前收发速率含义独立。2.4/5/6GHz 信道显示应符合系统返回频率；没有基本速率标记、未连接或未提供频率时显示未知，不猜测。附近列表为系统缓存。
7. 权限与服务：关闭 WLAN 服务、撤销位置权限或无无线网卡时，应给出明确状态；重新允许后可刷新。确认不自动连接热点，不修改无线配置。
8. 布局与生命周期：1000×670、正常尺寸、125%/150%/200% DPI 检查关键列、按钮、表格滚动条与状态提示；普通菜单可折叠。扫描/读取时快速切页或关闭，不能出现已释放控件异常或在新页填入旧结果。CSV 应跟随可见列顺序，并将潜在公式作为文本。
9. Wi-Fi 排版测试数据只由测试程序注入，正常程序不能出现样例 SSID/MAC。实机缺少数据时必须显示实际空结果/错误，不能以截图样例填充。

## V0.5.9 U 盘、路由列宽与鼠标验收

1. 插入自有 NTFS 和 exFAT/FAT32 测试 U 盘，列表应显示盘符及格式。选择非 NTFS 时权限设置/恢复禁用，并提示可使用本机 USB 写保护、仅影响当前电脑；不会请求管理员、递归改权限或格式化。切换 NTFS 后可用。
2. 刷新 U 盘及完成/停止只读检查后，非 NTFS 的权限按钮仍禁用；多盘选择刷新保留原盘。拔盘/换盘后操作需重新核对格式并显示可读失败原因。仅在已备份的 NTFS 测试盘验证原有权限设置/恢复，不能把界面模拟当作真实权限通过。
3. 在测试电脑核对原有本机 USB 写保护：需重新插拔，可能影响其他 USB 存储，按原备份恢复策略。到其他电脑不会自动受保护，不验证为跨电脑保护。
4. 路由与 MAC 对照用户截图：网卡、状态、MAC、IPv4、掩码、IPv6、网关间距收紧，网关比原来更靠前；状态表头横排，MAC/IP 不丢失。窄窗口可横向滚动，长值悬停可查，IPv6 模式网关/DNS 仍留足宽度。
5. 在 100%/125%/150%/200% 缩放下添加“移动鼠标”，点击捕获后把光标放到可识别目标，倒计时结束填 X/Y；完成后不抢焦点。点击“3 秒后测试移动”，核对回到同一点。参数为物理像素，不按缩放比例乘除。
6. 测试主副屏不同缩放、左侧/上方副屏负坐标；两种 BAT 引擎分别保存并重新生成运行，验证同一目标。分辨率或布局变更后重新抓取；UAC 安全桌面、光标锁定或输入权限不足应报失败，不能报成功到达。
7. 倒计时中切换动作/关闭编辑器，不得晚到回填或移动鼠标；读物理坐标失败时原参数保留并提示原因，不静默填逻辑坐标。倒计时中保存应提示等待。
8. 云端 323 项检查使用模拟 U 盘/鼠标接口及真实创建的界面；没有修改真实 USB 策略/权限或鼠标位置。以上 Windows 系统接口、缩放和设备行为仍需逐项实测。

## V0.5.7 扫描保存与卸载验收

1. 首次让自有测试学生机开机，选择同 VLAN 的教师机网卡，打开“扫描网段并保存”。不点击扫描时不应查询；核对默认网段、保存时的教室弹窗、全宽表格和最小窗口/DPI 布局。
2. 扫描自有 /24，对照实际 IP/MAC。无 TCP 端口探测；未响应不能显示离线。缓存来源和 ARP 解析来源应区别显示，不得声称已经确认学生机类型。
3. 跨所选接口网段及 /21 应在发包前拒绝；多网卡时应绑定选择的源 IP。大范围默认收至 /22，必要时分段；停止后等待在途 ARP 返回，不继续后续地址，关闭窗口不能出现控件异常。
4. 无 MAC 行不可勾选保存；重复 MAC 多 IP 应标记且批量勾选跳过，手选两条保存应拒绝。仅选择实际学生机，不把路由器或打印机作为学生机保存。
5. 修改新设备名称，勾选后在保存弹窗填写教室名称并保存；重启后记录仍在。再次扫描同 MAC 仅更新 IP，保留原名称/机房/备注，未响应的旧记录保留；失败不覆盖旧文件。
6. 关闭测试学生机后，直接选择保存的机房唤醒，不再扫描；只发送该机房 MAC，保存操作本身不发包。真实睡眠/关机支持仍按下方 WOL 条件验收，更换网卡需更新记录。
7. 软件表格搜索、排序后右键自有测试软件，确认窗口必须对应点击行。取消不能启动任何进程；确认后由该软件卸载向导继续，成功/取消完成后刷新清单核对。
8. 测试含空格路径、MSI 软件、用户/系统范围登记；Windows Installer 应显示正常卸载交互。无有效卸载路径、NoRemove、登记变化时给出提示，可打开 Windows 应用设置；不能直接删目录/登记项或假称卸载成功。
9. 云端 297 项检查包括模拟扫描、WOL 和卸载，并未执行真实 ARP/设备唤醒/卸载。请另记录本节 Windows 实测结果。

## V0.5.5 路由、代理与学生机验收

1. 两处路由：网络诊断点“查看路由表”应直接显示表格；路由/MAC 点路由标签使用相同列。前 3 列必须为目标、掩码、下一跳；对照 Get-NetRoute，默认路由前缀 0，IPv4 /24 显示 24，IPv6 /64 显示 64，目标列不拼前缀。
2. 切换 IPv4/IPv6，核对目标、下一跳、网卡、路由跃点；刷新、停止、快速切页后不能在新页填旧结果。当前表可导出 CSV，失败必须保留原因。
3. 代理：左侧属于网络诊断，试用分类中没有重复入口；进入不自动读取，原有脱敏和只读操作保持。
4. 清单：学生机管理为独立分类；新增、编辑、删除记录及重启软件后读取本机 TSV 正确。导入中文/带空 IP 清单、同 MAC 更新、重复 MAC/非法 MAC/超限数据核对，失败不能覆盖原清单。
5. WOL 准备：先选一台可测试学生机，启用 BIOS/UEFI 和有线网卡魔术包唤醒，保持电源/网线，教师机与它同 VLAN。记录其真实 MAC，分别测试睡眠和关机；硬件不支持关机唤醒时不得把 UDP 发送成功当作设备已开机。
6. 网卡/广播：教师机多网卡时选择正确源地址；对照实际掩码，/20 等广播不能简单取末字节 255。源地址变化后刷新；无可用网卡仍可维护清单，唤醒应提示选择接口。
7. 选中/机房：对单台、所选多台、指定机房核对仅这些 MAC 收到魔术包；机房批量不受搜索文字限制，其他机房不能混入。所有机房模式不得直接机房唤醒，进入页面不得发包。
8. 发包和结果：每个唯一 MAC 为 3 个标准 102 字节魔术包，UDP 9，绑定所选源接口；网络抓包可在自有测试网核对六个 FF 和 16 次目标 MAC。错误 MAC、跨网段已填 IP 必须在首个发包前拒绝。
9. 停止/故障：批量中停止、切页或关闭后不再继续后续包；已发送的包无法撤回，部分包数应如实显示。网线拔掉/源地址移除时显示发送失败；不根据发包成功自动显示在线或开机成功。
10. 云端测试与截图使用模拟发送，没有验证实际设备唤醒；需要记录真实设备、BIOS、网卡驱动及电源状态的验收结果。

## V0.5.4 布局与报告验收

1. 路由：每块网卡同一行显示 IPv4、独立数字掩码列、IPv6。对照 255.255.255.0 应显示 24，255.255.240.0 显示 20；IPv4 列不能拼 /24。无掩码/非连续掩码显示未知，不能自动当成 24。
2. 双栈：IPv4/掩码/IPv6 三列相邻；切换地址族时两种本机地址始终保留，网关、DNS、路由和邻居正确筛选。同网卡多 IPv4 地址与其掩码按相同顺序分号分隔，无地址不虚构 0.0.0.0。
3. Wi-Fi：SSID 至少 220 宽；表头为频率/信道/信号等短名，基本速率 Mb，频率值仍按 MHz、RSSI 按 dBm，单位可悬停核对。不得把 Mb/s 当成 MB/s 或下载速度。
4. 列顺序：RSSI 靠前、声明速率集末列；信号显示如 82%，点击信号表头排序时 9% 小于 82%，未知值不附 %。导出 CSV 的值、顺序、百分比与当前表一致。
5. 配置：系统/CPU/主板/内存/显卡/磁盘各一行，网卡每块一行。内存仅报告厂商、容量、频率与数量，两个相同 16G/3200 的模组合并 ×2，不同模组分别连接；缺少厂商或频率不得猜测。
6. 导出：采集完成选择是，TXT 内容直接可读且为同一部件摘要；选择否保留结果。导入新版 V2 和旧版 V1 后按摘要对比，同一配置不能只因格式不同出现差异；改变内存频率应只出现一条内存差异。重复 V2 字段或畸形报告应明确拒绝。
7. DPI：在 1000×670 和 125%/150%/200% 缩放核对表头不竖排、百分比与短单位不截断；长 IPv6、SSID 和完整支持速率可横向滚动/悬停查看。

7. 布局与响应：试用网络配置核对表格随窗口铺宽。启动即使数据库读取慢也先显示概览；硬件/启动项读取时快速切页、重复进入、关闭窗口不得卡住界面或往新页填旧结果。实机对比冷启动、首次/重复软件列表、启动项读取耗时，记录机器/DPI/软件数；云端结果不代表固定加速比例。

### V0.5.0 Windows 新增验收

先执行 `tests/Run-Windows.ps1`；以下为真实设备验收步骤，不代表云端已验证。

1. 导航：默认仅展开一个分类；点击分类文字和 +/- 均能展开收起。搜索 DNS、WiFi、打印机；回车打开首项，无结果没有可点击假入口。清空后恢复展开状态，重启后恢复最后页面。检查 125%、150%、200% DPI 与高对比度下可读性。
2. TCP 扫描：用本机测试监听端口验证“开放”，关闭端口验证“拒绝”，不可达地址验证超时；CIDR/端口数量/并发边界应拒绝。开始后停止或关闭窗口，任务停止后可导出已完成结果。不要把未响应当作设备离线。
3. 主机发现：使用已知的局域网 /24 与 /32，核对响应主机；V0.5.1 起仅用 Ping，禁用 ICMP 的设备即使 TCP 可连接也不能显示 Ping 成功。多网卡下确认用户输入的网段符合实际网络。
4. 路由/MAC/DHCP：与 `ipconfig /all`、`route print`、`arp -a` 对照，确认读取不改变配置。DHCP 服务器字段缺失不等于没有其他服务器。
5. DNS/TCP/HTTP：测试已知服务、404/401/405、302 跳转、超时与错误证书；不能自动跳转，不能忽略证书错误。停止应终止当前请求/命令。
6. Wi-Fi：核对接口、BSSID、信号、信道；没有网卡或位置权限时显示实际系统错误。普通配置报告不得出现密码。V0.5.6 起已保存配置按上方七列表格直接显示允许读取的密码，不再单独确认；普通报告仍不含密码。
7. 摄像头：选择相同 VLAN 网卡，已开启 ONVIF 发现的设备应能被发现；不支持设备可能无结果。错误网卡、设备无响应、防火墙限制均不能显示虚构设备。停止/关闭窗口后不得持续占用 UDP 套接字。声明地址仅作为文本，不能自动登录、打开或播放。
8. 回归：执行以下 V0.4.5 的原功能验收，尤其验证命令执行修改后的系统检查、SMB 诊断与取消逻辑。新代码未加入抓包、主动 DHCP 服务器发现、会话压力测试或 AI 接口。

## V0.4.6 及更早功能验收

建议在 Windows 10 和 Windows 11 各测试一次。先执行 `tests/Run-Windows.ps1`，再检查下列真实系统功能。自动化检查已在 Windows 环境通过；下列设备和界面操作仍需人工验收。

1. 配置对比：分别导出两台电脑报告，比较已知不同的 DNS/服务状态；同份报告比较应无差异。取消文件选择或导入无效文件应保留窗口可用。
2. 打印机：核对默认打印机、驱动及端口与系统设置一致。对测试打印机提交两个任务并确认取消，仅清理该队列。分别测试可达端口和关闭端口，TCP 测试不能产生打印任务。
3. 网络：对已允许 ICMP 的网关采样，核对 CSV 行数、时间和汇总；检测中断开网络再恢复，记录应出现对应状态。点击停止，等待当前探测结束，仍可导出。无 ICMP 响应不能判定为应用缺陷或断网。
4. 软件：导出完整登记清单，导入包含已装、未装、低版本以及非标准版本的软件要求；核对四类结果。覆盖 x86/x64 程序与当前账户安装的软件。
5. BAT：验证文件存在/不存在的两条分支、网络可达/不可达、Build 区间及嵌套。使用返回 0 和非零的测试程序检查等待、超时、重试次数；缺少结束、重复否则和非法重试参数应被拒绝。
6. U 盘：用没有可执行代码的文本文件命名为 `资料.pdf.exe` 和 `autorun.inf`，再放正常文档及指向记事本的快捷方式。扫描应显示依据且不能执行文件、修改内容或属性；导出报告后与原文件哈希/属性核对。拔出 U 盘时应报告读取失败而非卡死或安全结论。
7. Defender：对照 Windows 安全中心记录，核对名称、盘符和时间。没有历史应显示无法据此判断安全；关闭 Defender 或非管理员时应明确接口/权限错误。
8. 自动播放：记录原策略，关闭后核对 `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer\NoDriveTypeAutoRun`，重新登录验证；还原应恢复首次备份原值或原先不存在状态。
9. USB 写保护：同一管理员账户记录原策略并开启；重新插拔测试盘，尝试新建测试文件，确认设备实际拒绝写入。还原策略再插拔应恢复原先行为。若组织策略/设备驱动不支持，不能把注册表写入成功当作实际防护成功。
10. 窗口：检测进行中点关闭，应先请求停止，不应留后台扫描；检查小屏幕和 150% 缩放下按钮可滚动、结果可导出。
11. NTFS U 盘权限：使用空白测试 U 盘，先存入文件，再选择“普通用户只读”。在另一台 Windows 电脑以普通用户尝试读取、新建、修改和删除；用管理员账户核对仍可维护。回原电脑恢复权限，再核对原账户权限。另用 exFAT 测试盘确认操作被拒绝且不格式化。
12. 指定文件夹权限：只选无重要数据的测试文件夹，运行“取得指定文件夹权限”，核对 Administrators 所有权和完全控制，以及界面显示的失败项。
13. BAT 清空回收站：仅在测试账户中放入可丢弃文件，生成含该动作的 BAT，执行后核对当前运行账户在各盘的回收站。使用其他管理员账户提权时核对目标账户；不要在日常账户上试运行。

验收不要求导入真实恶意样本，不要在生产共享或重要资料上做取消打印/写保护等有影响的测试。
