# V0.5.3 Windows 验收

以下为真实设备待执行用例。先运行 `tests/Run-Windows.ps1`，再做实机检查；Linux 界面截图不能代替 Windows WLAN/权限/DPI 验收。

1. 导航：确认 6 个分类、29 个入口，安全维护功能均在系统与硬件下。即使旧导航文件保存其他页面，每次启动也必须先显示系统概览。
2. 直接页面：点击端口扫描、主机发现、路由/MAC、Wi-Fi 分析，不应出现中间“打开”按钮或弹窗。路由、Wi-Fi 自动读取且可刷新；主机页直接显示输入与 Ping 表格。
3. 端口：默认预设应有 125 个唯一常用 TCP 端口，也可自定义。用本机自有监听端口验证开放，关闭后验证拒绝；服务名只是参考，不能按端口推断实际软件。确认 UDP 不在此检测范围。
4. 纯 Ping：对允许与禁止 ICMP 的测试主机检测，结果应只取决于 Ping，不能因为 TCP 80/445/3389 可连接就显示“有响应”。未响应不等于离线。测试开始/停止及快速切换页面。
5. 路由/MAC：对照系统实际网卡、IP、MAC、IPv4/IPv6 路由、邻居缓存；网卡/路由/邻居应分表展示。读取失败需显示原因，不得把失败当作空结果成功。
6. Wi-Fi：对照真实接口与热点，检查接口 MAC 和 BSSID 不混用，频率单位 MHz，基本速率/支持速率/当前收发速率含义独立。2.4/5/6GHz 信道显示应符合系统返回频率；没有基本速率标记、未连接或未提供频率时显示未知，不猜测。附近列表为系统缓存。
7. 权限与服务：关闭 WLAN 服务、撤销位置权限或无无线网卡时，应给出明确状态；重新允许后可刷新。确认不自动连接热点，不修改无线配置。
8. 布局与生命周期：1000×670、正常尺寸、125%/150%/200% DPI 检查关键列、按钮、表格滚动条与状态提示；普通菜单可折叠。扫描/读取时快速切页或关闭，不能出现已释放控件异常或在新页填入旧结果。CSV 应跟随可见列顺序，并将潜在公式作为文本。
9. Wi-Fi 排版测试数据只由测试程序注入，正常程序不能出现样例 SSID/MAC。实机缺少数据时必须显示实际空结果/错误，不能以截图样例填充。

## V0.5.3 使用反馈验收

1. 软件清单：进入即显示六列表格，核对名称/版本/发布者/范围/登记区/位置；搜索与清空在缓存中进行，返回页面复用缓存，刷新重新读取。核对自定义要求、CSV 公式转义与停止，登记区不能当作真实二进制架构。
2. 搜索框：空输入无叉号；输入后清除图标在输入框内部，悬停、点击、键盘输入与回车导航正常。检查 125%/150%/200% DPI 无重叠。
3. 启动项：图标/开机启动/状态表头均横排，窄窗口时命令列不挤成零宽；读取/提取图标时窗口可拖动和切页，重复刷新/切页不持续增加 GDI 图像资源。确认启停权限与二次确认仍正常。
4. 路由/MAC：默认只显示 IPv4；切换 IPv6 后网卡、路由、邻居统一切换，地址/网关/DNS 不跨地址族混放。MAC/IP 显示完整，状态紧凑，IPv6 地址加宽且隐藏 IPv4 掩码列；速率单位 Mb/s 不等于下载速度。
5. BAT：上移/下移不再出现，☰ 拖动仍有效；复制所选行/Ctrl+D 后副本在下一行并选中，三个参数均保留，双击修改副本不影响原行。保存/加载/导出脚本保持动作顺序；复制条件/重试的单个动作后仍需维护结构闭合。
6. 配置报告：真实系统/架构、CPU、主板、内存、显卡、磁盘与网卡信息应准确；没有服务/SMB/共享清单。成功后弹出是/否导出提示，否不打开保存框且保留结果，是进入保存框；取消保存、采集失败不误报已导出，关闭采集窗口终止查询。
7. 布局与响应：试用网络配置核对表格随窗口铺宽。启动即使数据库读取慢也先显示概览；硬件/启动项读取时快速切页、重复进入、关闭窗口不得卡住界面或往新页填旧结果。实机对比冷启动、首次/重复软件列表、启动项读取耗时，记录机器/DPI/软件数；云端结果不代表固定加速比例。

## V0.5.2 新增待试用与硬件库验收

1. 五项新工具只位于“新增 · 待试用”。逐一进入，确认没有自动查询、跟踪或读取；点击执行后才工作，停止/切页后不回填旧页。
2. DNS：与 Resolve-DnsName 对照 A/AAAA/TXT/MX/SRV/PTR，测试中文域名、IPv4/IPv6 反查、无记录、服务器不可达与取消。非法名称/服务器不得执行命令，失败不能冒充空结果成功。
3. ICMP 跟踪：对照自有测试目标和 tracert -d，确认仅 ICMP、达到目标即停、最多用户设定跳数；禁止 ICMP 的目标允许超时且不能断定离线。跟踪停止和关闭应及时结束。
4. 本机连接：与 Get-NetTCPConnection / Get-NetUDPEndpoint 对照地址、端口、PID/进程。切换仅 TCP 监听过滤；UDP 仍是本机绑定，不能称为远端连接或可达。
5. 代理：对照当前用户、进程环境及 netsh winhttp show proxy；临时设置含假用户名/假口令/PAC 参数的测试值，界面及 CSV 不应带出凭据或 URL 路径/参数，完成后手工还原测试设置。工具不能下载 PAC 或更改代理。
6. 配置核对：用静态地址、DHCP、断网、VPN/桥接环境核对 IPv4、掩码、网关、DNS；不能因没有默认网关就断定隔离网有故障，也不能声称排除其他主机 IP 冲突。
7. 硬件：检查数据库原始计数为 572 硬件规则、PCI 2526/21819、USB 3427/20537。对照真实主板 SMBIOS 名称与设备 ID；WIFI/非 WIFI 型号不混用，内存前缀只给家族，未知型号保持原值。
8. 用户库：备份后在 pci.ids/usb.ids 中添加一个已有 ID 自定义名称，重载应优先显示用户条目；再次编译不能覆盖它。恢复原文件后再测精确型号和家族规则，详情应显示来源。

## V0.5.0 与更早版本回归清单

### V0.5.0 Windows 新增验收

先执行 `tests/Run-Windows.ps1`；以下为真实设备验收步骤，不代表云端已验证。

1. 导航：默认仅展开一个分类；点击分类文字和 +/- 均能展开收起。搜索 DNS、WiFi、打印机；回车打开首项，无结果没有可点击假入口。清空后恢复展开状态，重启后恢复最后页面。检查 125%、150%、200% DPI 与高对比度下可读性。
2. TCP 扫描：用本机测试监听端口验证“开放”，关闭端口验证“拒绝”，不可达地址验证超时；CIDR/端口数量/并发边界应拒绝。开始后停止或关闭窗口，任务停止后可导出已完成结果。不要把未响应当作设备离线。
3. 主机发现：使用已知的局域网 /24 与 /32，核对响应主机；V0.5.1 起仅用 Ping，禁用 ICMP 的设备即使 TCP 可连接也不能显示 Ping 成功。多网卡下确认用户输入的网段符合实际网络。
4. 路由/MAC/DHCP：与 `ipconfig /all`、`route print`、`arp -a` 对照，确认读取不改变配置。DHCP 服务器字段缺失不等于没有其他服务器。
5. DNS/TCP/HTTP：测试已知服务、404/401/405、302 跳转、超时与错误证书；不能自动跳转，不能忽略证书错误。停止应终止当前请求/命令。
6. Wi-Fi：核对接口、BSSID、信号、信道；没有网卡或位置权限时显示实际系统错误。普通配置报告不得出现密码。单独确认后按准确配置名显示密码，取消确认不读取；关闭敏感窗口后普通窗口仍不含密码，导出不得带入敏感窗口内容。
7. 摄像头：选择相同 VLAN 网卡，已开启 ONVIF 发现的设备应能被发现；不支持设备可能无结果。错误网卡、设备无响应、防火墙限制均不能显示虚构设备。停止/关闭窗口后不得持续占用 UDP 套接字。声明地址仅作为文本，不能自动登录、打开或播放。
8. 回归：执行以下 V0.4.5 的原功能验收，尤其验证命令执行修改后的系统检查、SMB 诊断与取消逻辑。新代码未加入抓包、主动 DHCP 服务器发现、会话压力测试或 AI 接口。

## V0.4.6 及更早功能验收

建议在 Windows 10 和 Windows 11 各测试一次。先执行 `tests/Run-Windows.ps1`，再检查下列真实系统功能。自动化检查已在 Windows 环境通过；下列设备和界面操作仍需人工验收。

1. 配置对比：分别导出两台电脑报告，比较已知不同的 DNS/服务状态；同份报告比较应无差异。取消文件选择或导入无效文件应保留窗口可用。
2. 打印机：核对默认打印机、驱动及端口与系统设置一致。对测试打印机提交两个任务并确认取消，仅清理该队列。分别测试可达端口和关闭端口，TCP 测试不能产生打印任务。
3. 网络：对已允许 ICMP 的网关采样，核对 CSV 行数、时间和汇总；检测中断开网络再恢复，记录应出现对应状态。点击停止，等待当前探测结束，仍可导出。无 ICMP 响应不能判定为应用缺陷或断网。
4. 软件：导出完整登记清单，导入包含已装、未装、低版本以及非标准版本的软件要求；核对四类结果。覆盖 x86/x64 程序与当前账户安装的软件。
5. BAT：验证文件存在/不存在的两条分支、网络可达/不可达、Build 区间及嵌套。使用返回 0 和非零的测试程序检查等待、超时、重试次数；缺少结束、重复否则和非法重试参数应被拒绝。
6. U 盘：用没有可执行代码的文本文件命名为 `资料.pdf.exe` 和 `autorun.inf`，再放正常文档及指向记事本的快捷方式。扫描应显示依据且不能执行文件、修改内容或属性；导出报告后与原文件哈希/属性核对。拔出 U 盘时应报告读取失败而非卡死或安全结论。
7. Defender：对照 Windows 安全中心记录，核对名称、盘符和时间。没有历史应显示无法据此判断安全；关闭 Defender 或非管理员时应明确接口/权限错误。
8. 自动播放：记录原策略，关闭后核对 `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer\NoDriveTypeAutoRun`，重新登录验证；还原应恢复首次备份原值或原先不存在状态。
9. USB 写保护：同一管理员账户记录原策略并开启；重新插拔测试盘，尝试新建测试文件，确认设备实际拒绝写入。还原策略再插拔应恢复原先行为。若组织策略/设备驱动不支持，不能把注册表写入成功当作实际防护成功。
10. 窗口：检测进行中点关闭，应先请求停止，不应留后台扫描；检查小屏幕和 150% 缩放下按钮可滚动、结果可导出。
11. NTFS U 盘权限：使用空白测试 U 盘，先存入文件，再选择“普通用户只读”。在另一台 Windows 电脑以普通用户尝试读取、新建、修改和删除；用管理员账户核对仍可维护。回原电脑恢复权限，再核对原账户权限。另用 exFAT 测试盘确认操作被拒绝且不格式化。
12. 指定文件夹权限：只选无重要数据的测试文件夹，运行“取得指定文件夹权限”，核对 Administrators 所有权和完全控制，以及界面显示的失败项。
13. BAT 清空回收站：仅在测试账户中放入可丢弃文件，生成含该动作的 BAT，执行后核对当前运行账户在各盘的回收站。使用其他管理员账户提权时核对目标账户；不要在日常账户上试运行。

验收不要求导入真实恶意样本，不要在生产共享或重要资料上做取消打印/写保护等有影响的测试。
