# 单机默认应用与文件关联

入口：**系统与硬件 → 系统修复 → 默认应用与文件关联修复**。原有“默认程序管理”入口也进入同一个窗口。

## 使用方法

1. 在表格中选择类别，或搜索扩展名、程序名称。Office、压缩与镜像、音乐、视频、图片、PDF/文本及网页/邮件协议集中展示。
2. 双击格式，或点击“选择默认程序”。
3. Win7/8.1 调用系统原生选择框，允许注册为默认程序，不执行样例文件；取消后不继续修改。
4. Win10/11 先在工具箱弹出的选择窗口中挑选已登记支持该格式的应用，再进入 Windows 确认。确认后关联会保留，不是“仅打开这一次”。工具箱不会在窗口关闭时就宣告修改成功。
5. 返回工具箱点击“刷新关联”，核对系统实际报告的默认应用。

较新的 Win11（23H2 及以后）可用微软支持的链接直达所选应用的默认设置页；Win10、较早的 Win11 进入默认应用总页，可能仍需按扩展名/协议定位后确认。不能保证在所有系统中只点一次就完成。

候选应用只从当前用户及本机的 RegisteredApplications / Capabilities 中读取，包括 32/64 位登记；不会执行候选程序。未列出不代表没有安装，可能未登记能力或读取受限，可用“系统中选择其他应用”。Office、解压软件和播放器须已安装，Windows 不自带完整 Office。

## 恢复系统推荐默认值

点击“恢复系统默认（指导）”：Win10/11 在系统默认应用页面找到重置全部默认应用的对应按钮，阅读提示后确认；Win7 没有统一重置全部的按钮，需要在默认程序中逐项指定。

重置范围由系统版本和已安装应用决定，不保证涵盖所有第三方格式，也不代表恢复到某次出厂镜像。修改针对本机当前账户；其他账户可能有自己的默认关联。默认程序保留到再次被用户、软件或策略改变为止，关联修复本身不会清除仍在运行的篡改程序。

## 文件与限制

Win7/8.1 选择框所需的空样例文件位于 `EXE目录/Data/AssociationSamples`，调用时不设置执行文件标志；不使用电脑 TEMP。工具诊断/操作日志沿用软件 Logs，不为此功能部署机房标准、登录策略或系统目录 XML。

Win10 起，微软明确规定 SHOpenWithDialog 不再能修改默认程序，其注册相关标志被忽略。这里不删除 UserChoice、不伪造关联校验，也不将一次打开或弹窗关闭当成永久设置成功。打开设置本身不需要工具自动提权。

云端完成 .NET 4.5 引用编译、分类/搜索/候选选择/取消/链接参数测试和真实窗口创建；没有改变真实 Windows 默认程序。原生选择框、实际设置保存与各版本兼容仍需实机验收。
