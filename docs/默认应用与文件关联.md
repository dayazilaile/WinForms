# 单机默认应用与文件关联

入口：**系统与硬件 → 系统修复 → 默认应用与文件关联修复**。原有“默认程序管理”入口也进入同一个窗口。

## 使用方法

1. 在表格中选择类别，或搜索扩展名、程序名称。Office、压缩与镜像、音乐、视频、图片、PDF/文本及网页/邮件协议集中展示。
2. 双击格式，或点击“选择默认程序”。
3. Win7/8.1 调用系统原生选择框，允许注册为默认程序，不执行样例文件；取消后不继续修改。
4. Win10/11 对文件格式优先通过 Shell 的 openas 动作请求 Windows 原生“打开方式”。弹窗若有“始终使用/始终”，选择它才会保存默认程序；选择“仅此一次”不会保存。系统可能在选择后打开软件目录中的空样例，应用也可能提示空文件格式错误。工具不把请求提交或程序打开当成默认设置成功。网页/邮件协议走默认应用设置，不访问虚构的测试网址。
5. 返回工具箱点击“刷新关联”，核对系统实际报告的默认应用。

原生弹窗的行为取决于 Windows 版本和关联状态，云端尚未验证哪些版本一定提供“始终”选项；不支持保存或调用失败时，用“按应用查找”作为备用入口。该入口先在工具箱列出候选应用，再进入系统确认。较新 Win11（23H2 及以后）可直达所选应用页；较早系统可能仍需在总页定位扩展名。不能保证所有系统只点一次就完成。

候选应用只从当前用户及本机的 RegisteredApplications / Capabilities 中读取，包括 32/64 位登记；不会执行候选程序。未列出不代表没有安装，可能未登记能力或读取受限，可用“系统中选择其他应用”。Office、解压软件和播放器须已安装，Windows 不自带完整 Office。

## 恢复系统推荐默认值

点击“恢复系统默认（指导）”：Win10/11 在系统默认应用页面找到重置全部默认应用的对应按钮，阅读提示后确认；Win7 没有统一重置全部的按钮，需要在默认程序中逐项指定。

重置范围由系统版本和已安装应用决定，不保证涵盖所有第三方格式，也不代表恢复到某次出厂镜像。修改针对本机当前账户；其他账户可能有自己的默认关联。默认程序保留到再次被用户、软件或策略改变为止，关联修复本身不会清除仍在运行的篡改程序。

## 文件与限制

原生文件选择所需的空样例文件位于 `EXE目录/Data/AssociationSamples`。旧版接口不执行样例；Win10/11 的 Shell 路径可能打开样例，不使用电脑 TEMP。样例存在且非空时停止打开，不覆盖用户改动，也不自动删除这些文件。工具诊断/操作日志沿用软件 Logs，不为此功能部署机房标准、登录策略或系统目录 XML。

Win10 起，微软明确规定 SHOpenWithDialog 不再能修改默认程序，其注册相关标志被忽略。本版 Shell 路径与这个旧接口不同，但仍不能保证具备保存选项。这里不删除 UserChoice、不伪造关联校验，也不将一次打开或弹窗关闭当成永久设置成功。打开设置本身不需要工具自动提权。
