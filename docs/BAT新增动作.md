# BAT 新增动作（V0.6.7，待试用）

完整工具箱入口：**新增 · 待试用 → BAT新增动作**。原来的 BAT 自动化也能添加这些动作；独立版打开后直接点“添加动作”。两个包使用同一份自动化源码。

| 动作 | 如何选择/填写 | 执行结果 |
| --- | --- | --- |
| 停止服务 | 点“选择服务”，搜索本机服务名称或显示名称；选择后自动填内部名称。等待默认30秒，可填1–120秒 | 在运行脚本的电脑重新查找准确内部名称，只停止服务，不禁用、不改启动类型、不连带停止依赖服务 |
| 结束进程 | 点“选择程序文件”选择应用主 EXE，自动填进程文件名；不需要PID。选择正常关闭或强制结束，默认等15秒，可填1–120秒 | 仅处理脚本所在登录会话中的全部准确同名进程；已退出则直接通过。正常关闭超时不会自动转为强制结束 |
| 重命名文件 | 选择文件，再填新文件名，例如 `课程表.xlsx` | 在同一个文件夹改名，不移动、不覆盖目标文件 |
| 重命名文件夹 | 选择文件夹，再填新文件夹名称，例如 `2026资料` | 在同一个父目录改名，原内容保留；不合并或覆盖已有文件夹 |

选择EXE只提取名称，不运行、不删除文件，也不按安装路径筛选实例。例如选择 `D:\应用\Demo.exe`，脚本运行时查找当前会话所有叫 `Demo` 的进程，而非只查这个路径。改名动作里的路径则是运行电脑实际使用的完整路径，换电脑使用要保证路径对应。服务列表只读取制作脚本的电脑，目标电脑必须存在同名服务。

强制结束可能丢失未保存内容；正常关闭遇到保存提示或没有主窗口的后台程序时可能超时/失败。服务依赖、权限不足、保护策略、进程重新启动等都会报出实际失败，不将它们显示为已经全部完成。停止服务可能需要管理员权限，沿用现有显式UAC选项，不绕过系统限制。关键Windows系统/安全服务、关键进程和当前脚本宿主不能选作停止目标。

文件的新名称要包含希望保留的扩展名；改后缀不会转换文件格式。新名称不填写路径、不允许通配符或Windows保留名称。已是相同名称会通过；发现重名、类型不符、链接/重解析点、受保护系统目录、当前BAT或其父目录等会停止，不自动覆盖。受保护范围包含当前用户标准目录；此功能用于普通文件/文件夹改名，不用于系统目录维护。

这四个动作允许放入条件分支；不允许放入重试块，避免重新命中的进程/服务/路径被反复操作。仍导出单个BAT，原启动、可见窗口、管理员申请、自删与网络审计选项保持。此版没有新增隐藏启动、混淆或杀毒排除规则，也不能保证所有安全软件放行。

## 核验范围

云端使用.NET Framework 4.5官方引用程序集编译，核验框架类型归属；界面检查使用模拟选择与服务数据，不改变真实服务或结束真实应用。脚本核验涵盖超时、权限失败、依赖服务、同名不同会话、句柄获取失败、部分失败、重新启动和路径冲突；改名使用可丢弃的真实临时文件/文件夹，内容完整性已核对。

Windows原生服务/进程权限、占用中的文件、中文路径、大小写改名及Win7/10/11真实效果仍需实机验收。Server冻结版不改动。源码对照与检查数量见 `validation-v067.json`。
