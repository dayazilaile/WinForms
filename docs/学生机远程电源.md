# 学生机远程关机、重启与撤销

入口（v0.6.4 起）：**新增 · 待试用 → 学生机远程电源 → 远程电源 ▾**。原学生机管理页保留“远程电源（待试用）”跳转按钮。因实机失败反馈暂不视为已验收。

1. 选择教师机连接该机房的网卡。学生机清单需要保存当前 IPv4 和 MAC，只有 MAC 的唤醒记录不足以发送远程电源请求。
2. 选择表格中的学生机，或在机房列表选择一个具体机房。
3. 菜单提供“关机选中”“重启选中”“取消选中待执行关机/重启”，以及对应的整个机房操作。整个机房包含该机房的全部记录，不受搜索文字影响；“全部机房”不能一键关机或重启。
4. 在确认窗口核对机房、学生机名称、IP、MAC 和数量后执行。关机/重启默认 **60 秒倒计时**，不请求强制关闭未保存的应用，因此应用可能阻止完成。
5. 结果表格显示目标是否接受请求或失败原因。接受请求不等于已经关机、重启或成功撤销；工具不会假造实际完成状态。

## 权限与适用范围

目标机必须允许**当前 Windows 账户**远程关机，Windows 远程管理/RPC 服务及相应防火墙规则需可用。普通账号、不同机器的本地账号限制、组织策略和防火墙均可能导致拒绝。无需在学生机安装本工具的代理，但只知道 IP/MAC 并不代表有权关机。

本工具不保存密码，不自动开启防火墙规则、不降低 UAC、不改账户权限，不通过启动项或后台服务驻留。由管理员按现有管理规范配置目标机权限。常见错误会区分拒绝访问、RPC 不可达、已有待执行关机及没有可撤销请求。

只对所选局域网内的已保存主机 IP 操作。整批预检会拒绝本机地址（包括其他网卡）、回环、特殊地址、子网号、广播地址、重复 IP/MAC 和缺失 IP。派发前还会重新检查本机 IP，防止地址变化后误操作教师机。

每台提交前用所选接口进行 ARP 解析并核对保存的 MAC；无法解析或不匹配时不提交。ARP 可能使用缓存或受代理影响，是降低旧 IP 误操作风险的检查，不能当作加密身份认证；设备记录仍需使用者核对。

## 停止与撤销的区别

- **停止**：阻止后续目标继续发送；已经进入原生 RPC 的当前请求可能仍返回，工具会保留其结果，不把它丢弃或伪称已撤销。
- **取消待执行关机/重启**：向目标机明确提交 Windows 撤销请求。需要同样的远程权限，且不能逆转已开始或完成的操作。
- 正常关闭工具箱时，若电源请求仍未返回，会提示等待结果；可先停止后续发送再等待当前请求返回。系统强制结束进程/关机无法保证留下最后结果，也不会撤销已接受的远程请求。

请求顺序执行，跨页面的请求也串行；切页会停止后续发送，当前请求仍可能被目标接受。不会启动额外的关机脚本、PowerShell 或 shutdown.exe 进程。

## 记录位置

学生机清单继续是 `EXE目录/Data/students-v055.tsv`，本功能不改清单格式或存储路径。电源请求结果是当前页面显示数据。

操作日志写在 **EXE目录/Logs/operations-v1.tsv**：沿用教师机主机名、硬件/网卡标识、账户、时间、版本与操作编号，并记录目标机房、学生机名称、目标 IP/MAC、动作、接受/失败及错误信息。

启动关机/重启前必须成功写入开始记录；日志不可写就不提交。撤销请求仍会尽力发送，日志失败时在结果中提示保留界面信息，不会转存电脑用户目录。Windows 自身及目标机仍可能留下系统关机事件，这些不是工具日志。

云端测试完全使用模拟 ARP/RPC 和固定文档网段数据，没有对真实学生机进行关机、重启或撤销。真实权限、Win7/10/11 原生调用与防火墙兼容仍需在授权的闲置目标机上验收。

## v0.6.4：“找不到网络路径”怎么排查

该文字通常对应 Windows 错误 **53**。它表示远程管理所需的网络路径未建立，不能仅凭这个错误断定是哪条防火墙规则，也不能因为能扫描出 MAC 就认为可以关机。错误 **1722** 是另一项 RPC 服务不可用结果；**5/1314** 需要检查访问权限/用户权利。

1. 在试用远程电源页选择实际连接该机房的网卡、选中学生机，点击“检查远程条件”。只读核对 MAC 和 TCP 135/445；不发送关机/重启，不登录目标，也不更改设置。
2. MAC 不符或无法解析时先重新扫描、核对 IP/MAC。端口不可连或超时只表明当前 TCP 通道不通，可能与主机在线状态、路由、服务或防火墙有关。135/445 都通也不能证明具体 RPC 接口、命名管道和账户权限满足要求。
3. 双击结果行、右键“查看完整结果”或点击“结果详情”。完整文字包含时间、目标机房、清单名称、IP/MAC 和结果。原生电源请求还列出 Windows 返回码；身份预检失败会写“未调用/未取得”，不伪造原生码。
4. 导出“本机只读检查 BAT”，分别在教师机和目标学生机本机运行；完整本地用户权利导出需要已有管理员权限。检查服务状态（含 Workstation/Server/RPC）、本机网络/监听、防火墙当前配置和远程关机用户权利。RemoteRegistry 状态仅供核对，不表示所有系统都必须启用该服务。
5. 由网管根据检查结果处理实际网络/服务、相应防火墙规则和目标机远程关机授权。工具不一键关闭防火墙、不开放全网端口、不禁用 UAC、不配置空密码或缓存凭据。完成必要的授权配置后，再在闲置学生机重试。

只读脚本普通明文 CMD，不运行 PowerShell、不更改执行策略。结果在 **BAT所在目录/Logs/RemotePower-主机名.txt**；本地权限导出与 secedit 自身的工具日志也在这个 Logs，重复检查追加主记录。导出不等于执行；非管理员/命令缺失/读取受限会记录失败或保留未知项，不声称修复成功。脚本仍可能受组织程序策略限制。

本地只读收集用于明确用户反馈，不是原批量软件清理脚本；清理脚本仍按原要求不输出报告或脚本日志。

## 跨网段唤醒

当前 WOL 发到**所选本机网卡的子网广播地址**，且拒绝清单中不属于该子网的 IP。即使两个网段能正常访问，路由器通常也不会转发这种广播。

跨网段方案需要目标机房所在网络有常在线的中继设备代发，或由网管为路由器配置受控定向广播/WOL 转发。VPN 只有在能正确传送所需广播或连接中继时才有帮助。当前版本没有提供中继服务，不能将“保存多个机房”误认为“已经支持跨网段”。

关机学生机的 MAC 仍需预先保存。网卡有待机供电不保证它关机后响应 ARP；开机单播依赖的路由/邻居缓存也可能过期。WOL、在线扫描、RPC 关机是不同通道，分别验证。
