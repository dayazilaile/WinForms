# 一键系统优化与开机临时文件清理（v0.6.6 待试用）

## 入口与执行

入口为“新增 · 待试用 → 一键系统优化”，原“系统与硬件 → 系统优化”也有直达按钮。进入只显示配置，不自动执行。点“检测本机”读取机型、Build和域状态。

“一键推荐优化”选中10个推荐项并展示确认；“执行勾选优化”仅执行所选项目。可点“选择全部配置项”再按需取消。包含管理员项目时先以管理员重开，工具不会为权限不足就偷偷降低UAC。使用另一管理员账户运行会处理那个账户的HKCU/Temp，不是原桌面用户；恢复也校验账户。

推荐项：电源、扩展名、天气/搜索、资源管理器、系统广告推荐、传递优化、预览处理器/缩略图、桌面图标、文件历史记录、时间同步。D盘、网址代理和自动更新策略默认不勾选，确认适用再选。双击一行看完整说明、结果和备份路径。

## 电源

台式机和笔记本均尝试高性能。已有标准高性能计划或名为“高性能”的计划时使用；没有则创建新GUID计划，名称仅为“高性能”。优先复制系统高性能模板，模板不可用再尝试复制原计划并设置CPU上下限100%，结果说明来源，不将其冒充完全相同的系统出厂模板。

AC/DC可用的屏幕关闭、普通睡眠、无人值守睡眠、自动休眠超时设为0；笔记本合盖动作0（不操作）。不关闭低电量和热保护。识别失败时不猜测盖子动作。现代待机、OEM或组织策略可能限制创建/写入，必要参数不可读时报告未完全应用，保留恢复记录。

恢复还原原活动计划、原已有目标计划的参数/名称，删除本次新建计划。若原计划已被其他软件删除，不猜测替代。不会用“恢复所有电源默认值”抹掉其他OEM方案。

## 文件、任务栏与系统设置

- 扩展名：HideFileExt=0，保留受保护系统文件的隐藏设置。
- 天气/搜索：Win10配置Feeds及搜索图标，Win11配置Widgets及搜索图标。写值核验不代表界面已刷新，部分新版本/管理策略可能忽略。
- 资源管理器：Win10/11默认此电脑，关闭最近与常用展示；Win7/8不写不存在的对应功能。
- 广告推荐：按已知用户开关关闭开始菜单、锁屏及资源管理器推荐，不卸载应用。
- 传递优化：DODownloadMode=0，使用HTTP下载，关闭P2P，不等于停止系统更新。
- 预览：启用已安装预览处理器与缩略图，Office/PDF等格式依赖实际处理器。当前预览窗格请在资源管理器用Alt+P显示/隐藏，不用不可靠按键自动反转。
- 桌面：显示此电脑、控制面板、网络并发送刷新通知。
- 文件历史记录：设置禁用策略，不删除既有备份，不修改系统还原。Win7没有该功能会跳过。
- 校时：备份W32Time启动/运行及NTP参数，保留域或现有有效NTP配置，启用后执行一次立即同步并显示命令状态；网络/权限失败单列。域状态未知时跳过，避免改变单位时间源。恢复不把系统时间拨回去。
- 自动更新：NoAutoUpdate配置可恢复，未停用更新服务/病毒库/Office/商店更新，不绕过组织策略，不承诺永久或所有系统都执行该策略。

实时防护、UAC和防火墙不在自动优化项目中。界面仅提供防护只读查询和UAC原生设置入口；此前这部分尚未最终确认。

## D盘保存位置

只有明确选择后才执行。先检测D盘就绪、Fixed、连接总线和写入条件；已识别USB/移动/网络或未知类型跳过，不自动猜其他盘。Appx卷要求NTFS。

“新文档/音乐/图片/视频到D盘”使用Windows标准文件夹API，目标为D:/UserData/账户标识/对应文件夹。它改变当前用户的标准保存位置，不搬迁旧文件，也不控制所有软件自己的保存规则。OneDrive、网络重定向、重解析点等情况整组跳过。旧文件仍在旧位置，应用可能需重开。

“新商店应用默认安装D盘”使用Appx默认卷API；D尚无应用卷时会尝试注册D:/WindowsApps。普通EXE安装器不受此设置控制，现有应用不迁移。恢复只还原默认卷，不删除D上新注册的卷、已安装应用或文件夹；原卷不见时停止而不猜测。

Windows原生“新内容保存位置”也保留入口，其他类别可在系统页面核对。

## 网址与主页

自定义项明确限于当前用户：关闭代理、移除PAC URL、把传统IE主页设为about:blank，并支持按原值恢复。不清空DNS/hosts、不批量删除浏览器快捷方式参数、不覆盖Edge/Chrome或企业主页策略。若劫持来自其他来源，先用代理诊断核对，需针对具体浏览器处理，不能称为通用解除所有网址锁定。

## 图标与资源管理器维护

刷新系统图标、清理/重建图标缓存、重启资源管理器都是独立按钮，不跟随推荐优化自动运行。缓存重建只删除当前账户的IconCache.db与iconcache*.db，不删除用户文档或桌面快捷方式。

重启前确认，可能关闭文件夹窗口；请先完成复制/移动等操作。只处理可确认属于当前账户、当前会话且路径为系统Explorer的进程，不批量结束其他会话。即便清理失败也尝试重新启动Explorer，返回的是请求结果，不假称任务栏必然已恢复。

## 开机（解决欢迎加载慢）

单独入口“开机临时文件清理”，也可从优化页进入。点击并确认才清理当前运行账户Local/Temp，默认保留最近24小时，可取消该选项。占用/只读文件、链接和工具箱自身目录跳过；不清理整个Local、不改启动项，空目录保留。

Windows使用独占文件句柄核对最终路径再删除，避免重解析路径把清理引向Temp外。停止返回已完成数量，不能撤回已删除文件。显示的是文件逻辑大小总计，因此为约释放空间。欢迎慢可能还与域登录、用户配置、网络或服务有关，不能保证清Temp解决。

## 备份、恢复与记录

备份：EXE目录/Data/Computers/电脑名/Optimization/时间-GUID.xml；日志：EXE目录/Logs/operations-v1.tsv。备份中包含设备、账户、系统Build和各项目的原状态。编码保存的原值只是数据，不作为脚本执行。

每项先捕获原值、写入备份并记录执行意图，然后才修改；完成后记录核验/失败。备份无法写入就不开始修改；修改后记录失败会停止后续项目，原执行意图可用于恢复检查。不回退到电脑用户目录。请保持软件目录/U盘可用。

“恢复本次”使用本页最后一次备份，“选择其他备份”可选择更早的XML。按反序恢复已执行和部分修改项，失败可重试，已恢复项跳过。设备标识、账户或系统Build不同会拒绝；机器重命名或备用硬件标识变化也可能需要人工核对，不自动跨机套用。

恢复的是配置，不搬运文件、不回拨时间、不恢复Temp/缓存；也不清除用户随后创建的D盘内容。设置组并非Windows事务，若中途失败可能已有部分修改，界面会保留“需检查/恢复”而不是伪称全成功。停止只影响后续项目，当前修改会先完成核验/落盘。

本功能先放待试用。云端不执行真实系统优化、D盘重定向、校时、Explorer结束或用户Temp清理；Windows原生效果和USB文件系统仍需实际验收。
