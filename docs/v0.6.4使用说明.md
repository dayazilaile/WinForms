# v0.6.4 使用说明

## 软件清单 BAT 在哪里

推荐从左侧 **新增 · 待试用 → 软件清单清理BAT** 进入。它是原有清理能力的新入口，不是新增一套卸载内核。

1. 在软件配置正确的电脑点“建立 / 编辑标准”，进入软件环境检查。
2. “标准清单 ▾ → 从本机建立标准清单”，勾选要保留的软件并保存；已有标准也可以直接导入。标准在 EXE目录/Data/software-baseline-v1.tsv，升级时保留自己的 Data。
3. 回到试用向导读取标准，点“生成清理 BAT”；原软件环境检查页也有直接可见的“导出清理 BAT”按钮。
4. 生成时选“确认后批量卸载”或“自动执行”，保存一个 BAT。自动模式仅使用登记的静默卸载方式，不猜测参数。
5. 在要处理的学生机交互桌面运行。脚本重新读取**那台电脑**的软件，对照保留标准；不会使用教师机的卸载路径。正常 UAC 和保护组件跳过规则保持原样，结果只弹窗，不额外保留报告/清理日志。

没有有效标准时不能生成，不会把所有软件直接作为多出项。原入口仍为 **系统与硬件 → 软件环境检查 → 标准清单 ▾ → 导出批量卸载脚本**。保存 BAT 只生成文件，不执行卸载。

## 关机失败怎么看

试用组内打开“学生机远程电源”或“远程电源诊断”。选中机器，先“检查远程条件”，再双击结果看完整详情。只有 MAC、Ping 或端口可达都不足以证明能关机。

“找不到网络路径”通常为 53；1722 是 RPC 服务不可用，5/1314 为访问/权限问题。可以导出本机只读检查 BAT，在教师机和学生机分别收集。详见 [学生机远程电源](学生机远程电源.md)。本版改善定位和入口，不声称修复了机房防火墙或授权配置。

## 新旧功能怎么找

新增组含“新增功能总览”，显示版本、状态与用途。旧能力的新入口明确标注；历史试用功能没有可靠加入版本时显示“历史”，不补写猜测的版本。原学生机管理保持扫描、机房保存和同网段唤醒，远程电源从其按钮跳转到试用区。

新增/待确认功能先放试用组，按实际反馈再决定保留位置。用户已确认的默认软件功能维持原实现。
