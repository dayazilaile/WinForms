V0.2.6 BAT 自动化——测试建议

A. 最简单的延时测试
1. 用「添加动作」依次加入：运行程序 notepad.exe、等待毫秒 1000、输入文字 测试完成。
2. 启动前延时设为 3 秒，选择方案 A，隐藏运行不勾选、自删除不勾选。
3. 生成 BAT 到测试文件夹，双击观察动作是否完成。
4. 将方案切换为 B，重新生成另一份 BAT，对比 Win10/Win11 的执行效果。

B. 隐藏运行测试（非破坏性流程）
1. 只加入「等待毫秒 1000」，勾选「隐藏运行窗口」。
2. 生成 BAT 并双击，注意 BAT 初始窗口可能短暂闪现。
3. 隐藏模式不会生成 .run.log，无法从日志确认步骤；需要排查时请先取消隐藏；隐藏模式没有可见 Ctrl+C 中止入口。

C. 自动删除测试（非破坏性流程）
1. 只加入「等待毫秒 1000」，勾选「成功后15秒自删除 BAT」。
2. 先复制一份备份，再运行生成的 BAT。
3. 脚本执行成功后延迟约 15 秒尝试删除；失败应保留脚本。

D. 磁盘格式化
1. 涉及格式化指定卷时，「隐藏运行窗口」和「自动删除 BAT」将被禁用。
2. 不要在有重要数据的电脑或测试分区之外验证格式化功能；不同电脑的盘符可能不同。
3. 该动作会清除卷数据，需管理员权限，无法由脚本保证恢复。

E. 导出和保存
1. 保存工作流后，再重新打开，确认引擎、隐藏勾选、启动延时、自删除勾选均恢复。
2. 两种引擎都导出一个 BAT 文件，目标电脑不必安装工具箱，但要有 Windows PowerShell。

当前环境未完成 Windows 实机编译验证；编译报错请保留完整输出。

IT 桌面运维工具箱 V0.4.2 —— 共享访问认证与网络设置增强

主要改动（基于 V0.4.1 CompileFix1，保留历史功能）
1. 共享文件夹列表不再错误地把每条共享标成“已配置（访问需验证）”，改为“已创建（认证状态待检测）”。
2. 共享文件夹主页面新增“共享认证模式（账号 / 来宾）”。按本机所扮演的角色分成：
   - 本机访问别人电脑的共享（SMB 客户端）：要求用户认证（禁用来宾、强制客户端签名）/ 无需账号来宾兼容（允许不安全 Guest、取消客户端强制签名）/ 恢复。
   - 别人访问本机共享（SMB 服务端）：要求用户认证（经典本地账户认证映射、强制服务端签名）/ 无需账号来宾兼容（ForceGuest=1、取消服务端强制签名）/ 恢复。
   - Guest 账户启用/禁用和恢复独立操作，防止无意开启账户。
3. SMB 诊断页顶部直接显示“关闭客户端强制签名”“开启客户端强制签名”“恢复签名原值”，对应 Set-SmbClientConfiguration -RequireSecuritySignature $false/$true。
4. 网络共享设置页增加专用/公用网络的“网络发现”和“文件和打印机共享”规则状态读取及开/关/恢复按钮，按 Windows 防火墙规则名称匹配 NETDIS-* 和 FPS-*，不依据本地化显示组名称。
5. 本机 Guest 配置、签名、来宾模式更改均需管理员权限和明确的二次确认，首次备份原值，重新读取验证结果。拒绝在域成员电脑做服务端 Guest only 修改，公用网络下不启用本机 Guest。

重要说明
- 客户端允许 Guest 与服务端提供 Guest 是两回事：访问 \192.168.1.100 时，必须在 192.168.1.100 配置服务端；本机开关不能更改目标电脑。
- 免账号访问仍取决于 Guest 账户、共享权限、NTFS 权限、服务器和客户端的安全策略、网络防火墙、SMB 协商，不能保证点一次就能访问。
- “密码保护共享”不是客户端 RequireSecuritySignature 的别名，也不能简单通过 EnableAuthenticateUserSharing 代替。该版不使用未经确认的注册表捷径伪造其开启/关闭结果。
- 禁用强制 SMB 签名、启用不安全 Guest 或 ForceGuest 会显著降低网络安全，只适用于隔离的可信测试环境；日常建议有密码的 SMB2/3 账户共享。
- 高级共享中公用文件夹共享、共享加密等的显示/修改能力随 Windows 版本不同，不保证所有 GUI 选项都能由单一 PowerShell 命令稳定等价实现。本版仅对已知可检验的状态提供修改。
- Windows 真机编译 / 安全软件误报 / 与不同 SMB 服务器的兼容性尚未验证；本包只是完整源码测试版，请在非生产机器上先编译、测试。

已知仍需继续验证的旧问题：火绒在关闭跨机房诊断时对导出的自动化 BAT 的安全告警。此版未修改自动化执行引擎，也未试图规避检测。

IT 桌面运维工具箱 V0.3.7 —— 静态 IPv4 配置结果验证修复

本版本基于 V0.3.6 完整源码，只改动网络配置相关代码和版本说明。

本次定位：
1. 旧版 NetworkConfigService.ApplyIPv4 调用 netsh 后直接继续下一条命令，不判断退出码。静态 IP 设置失败时可能仍显示 DHCP，却没有明确错误提示。
2. 旧版在网关留空时仍带 gwmetric=1。微软 netsh 文档仅在指定网关时使用 gwmetric。
3. 旧版完成后刷新界面会自动重置选择框，若静态配置失败，设置项会重新显示 DHCP，容易误以为软件主动切成了 DHCP。

本次修复：
1. 记录 netsh 的实际命令、退出码、标准输出和错误输出。
2. 设置静态 IP 时只在填写网关的情况下添加 gwmetric=1，并显式 store=persistent。
3. 修改 IP 后，根据网卡 ID 重新读取实际 DHCP 模式和 IPv4 地址；若不符合预期，则立即停止 DNS 设置，输出错误和实际状态。
4. 设置 DNS 后再次验证 IPv4 与 DHCP 模式，确保不把失败报为成功。
5. 修改失败后保留用户刚刚输入的 IP、掩码、网关、DNS 文字，便于检查和重试；实际模式由系统重新读取。
6. BAT 自动化“设置静态 IPv4”步骤也增加静态状态与 IPv4 复核，避免 netsh 返回码成功而实际配置没生效时继续执行后续步骤。
7. 不自动将静态 IP 配置失败的网卡改为 DHCP，也不自动回滚。现有“恢复最近网络配置”功能仍保留。

注意：
- 应以管理员权限运行工具箱；在现场或有带外访问手段时测试 IP 修改，远程修改可能断线。
- 修改前自动保存原配置参数；备份并非自动回滚功能。
- 如果 Windows 组策略、第三方网管软件或 DHCP 服务后续强制覆盖 IP，软件会报告它在验证时观察到的实际状态，但不能保证后续一直不变化。
- 本 ZIP 在非 Windows 环境完成了源码静态检查及文件完整性检查；尚未在 Windows 真机编译和实际修改网卡验证。

新增动作：删除桌面指定文件
- 参数1：精确文件名，例如 误发通知.docx、错误软件.lnk、无用资料.pdf。
- 参数2：选择「当前用户桌面」「公共桌面」「两者」。
- 参数3：无需填写。
- 不接受完整路径、文件夹名、通配符 * ?、路径分隔符、desktop.ini 等危险输入。
- 运行时调用 Windows 的桌面已知文件夹路径，兼容当前账户桌面重定向（例如 OneDrive）。
- 找不到文件就打印 [SKIP] 并继续；确实删除后显示 [OK] 和完整路径。
- 误填文件夹则停止，避免递归删除；遇到删除权限错误会停止。
- 删除是永久删除，不进回收站。若桌面同步到云端，删除可能同步到云端。
- 普通账户运行时通常可删除自己桌面的文件；公共桌面可能需要管理员权限。
- 新建流程的「使用管理员身份运行（自动弹出 UAC）」默认勾选（不绕过 UAC）。
- 若以另一账户提供管理员凭据，当前用户桌面会解析为提权账户，而非屏幕上原登录账户的桌面。
- 旧 .workflow.txt 兼容：动作字段及序列化格式保持不变；其他 BAT 动作原样保留。
- 修改内容仅涉及 AutomationService.cs、MainForm.Automation.cs，以及说明与编译批处理版本提示。

测试建议：
1. 在一台机器桌面新建占位文件 误发测试.txt。
2. BAT 自动化 → 添加动作 → 删除桌面指定文件；文件名 误发测试.txt，范围 当前用户桌面。
3. 先不启用隐藏运行、自删除，生成 BAT 在该电脑双击（或按需接受管理员 UAC）。
4. 确认控制台 [OK]、文件确实消失；再次执行应提示 [SKIP]。
5. 测试完毕再到其他机房批量分发，切勿用真实文件直接首测。

注意：此版本在 Linux 环境完成静态校验，不能代替 Windows csc.exe 编译与真机运行验证。

IT 桌面运维工具箱 V0.3.4：跨机房自动化诊断 / 自动 UAC 授权

1. BAT 自动化 → 勾选【使用管理员身份运行】，导出的 BAT 自检管理员令牌，不满足时请求 Windows UAC 授权后再重启自身运行；用户可取消，不绕过 UAC。

4. 键盘操作完成后增加 100ms 缓冲，帮助接收程序处理键盘消息，但这不构成“目标窗口已处理按键”的保证。

8. 推荐先运行根目录「跨机房输入环境诊断.bat」（非管理员），同一机器再右键管理员运行进行对照；如需排查生成 BAT，关闭隐藏，打开环境诊断再测试。

建议工作流：启动程序 → 等待窗口 → 激活窗口 → 等待 500ms → 鼠标移动/点击目标输入框 → 输入文字/按 Enter。
仅当已核实目标程序确实需要高权限时勾选管理员，UAC 弹窗后需要重新激活目标窗口。
本包在 Linux 工具环境完成静态检查/ZIP 完整性检查，未在 Windows 真机编译或运行。

IT 桌面运维工具箱 V0.2.2 完整源码 / 在 V0.2.1 上整合

一、针对真实测试反馈的修复
1. 创建共享 / 映射网络驱动器：先复制文本框参数，再关闭对话框，后台不再访问已经释放的 Windows 控件；修复 CreateHandle/Dispose 异常来源。
2. 创建 SMB 共享：优先使用 Windows New-SmbShare，利用 S-1-1-0 SID 解析本地语言的 Everyone 名称，支持中文自定义共享名；验证共享权限。若共享名已经存在、操作受系统限制或文件夹权限不足，显示明确的命令报错。仅创建只读共享，不调整 NTFS 权限。
3. PowerShell 输出：强制文本格式及隐藏普通进度输出，减轻 CLIXML 输出噪声。安全防护批量操作返回码为0并不表示所有保护已成功关闭；始终展示实测 Defender / 防火墙状态。程序不会绕过 Windows 篡改防护、卸载安全组件或修改组织管控策略。
4. 启动项：增加程序图标列。图标来自本机文件（EXE、快捷方式等），获取失败时使用通用程序图标；用户仍可查看原始启动路径。修复复选框因表格只读导致无法切换的情况。
5. 功能开关：第一列采用复选框，勾选=开启，取消勾选=关闭；未设置的注册表值使用灰色不确定状态，点击即确认后操作，再重新读取值。
6. 网络配置弹窗：异步修改 IP/MAC 前快照输入值，避免后台线程读取 WinForms 文本框。

二、BAT自动化（两种方案共同支持）
- 原有新版 SendInput / 传统 mouse_event 两种方式均保留，仍导出可独立使用的 BAT 文件。
- 新增动作：设置 DNS、设置默认网关、设置静态 IPv4、IP及DNS切换 DHCP。
- 参数1支持网卡明确名称，以及“自动有线” / “自动无线”；自动筛选超过一块或没有设备时拒绝执行，避免乱选。
- 生成的 BAT 在执行网络操作前检测管理员权限，备份当前 IPv4 配置到目标电脑的 %%TEMP%% 目录，操作后输出当前配置；不要求安装工具箱。
- 注意：多个电脑使用相同静态IP可能导致地址冲突；更改IP或网关会造成远程会话中断。必须先在测试机验证。
- “设置默认网关”动作仅对静态 IPv4 网卡实施，不自动覆盖 DHCP 分配的网关。

三、源码与编译
1. 完整解压，双击 Build_And_Run.bat 编译；需要 Windows 自带 .NET Framework C# 编译器。
2. 旧版本可保留对照。本版本可直接单独重新编译，不需要合并补丁。
3. 本环境没有 Windows 编译器：仅做静态代码检查、数据库检查、ZIP CRC 验证。不能保证功能已通过实机运行。
4. 请先在非生产机测试共享自定义名字、启动项勾选和网络BAT生成，执行网络脚本前准备回退手段。
