  第①步：先将相互通信的局域网设为“专用网络”，在两台 Win11 各点击“配置本机双向来宾模式”（管理员权限、二次确认）。

安全提醒：Windows 11 24H2 等版本默认可能强制签名，Guest 兼容模式可能需要降低本机 SMB 保护，仅适合隔离可信测试网络，不建议在承载敏感数据的学校/企业办公网长期开启。工具不启用 SMB1、不开放整个磁盘、不改其他电脑设置。

IT 桌面运维工具箱 V0.4.0 · 完整源码版
========================================

一、第一次编译
1. 将本 ZIP 完整解压（不要只提取 C# 文件）。
2. 打开和 src、Database 同级的文件夹。
3. 双击 Build_And_Run.bat，编译成功后自动打开软件。
4. 以后可以直接运行 build\ITDesktopToolkit.exe；移动到其他电脑时请连同 build\Database 一起复制。

一键编译依赖 Windows 10/11 自带 .NET Framework 4.x 编译器 csc.exe。
如果系统缺少该编译器，脚本会提示，不会自动下载或安装任何组件。

二、这是一份完整整合版本，包含此前已有的全部主要模块，以及本轮新增的：
- 启动项管理（当前用户及授权管理员的所有用户 Run/启动文件夹；支持复选框状态读写）
- 网络 IP、子网掩码、网关、DNS 配置，MAC 更改/尝试恢复，操作前保存网卡信息
- 蓝屏/异常关机/服务/磁盘故障日志增强，保留事件原始字段
- 77 条蓝屏代码、36 条常见事件规则、85 条通用错误码的本地文本库
- WIA (stisvc) 服务重启
- RDP 端口读取与修改（不静默改防火墙、不自动重启服务）
- 显示器红/绿/蓝/黄/白/黑/灰全屏检测
- SMB 共享列表、创建只读共享、取消共享、映射网络驱动器
- Windows 安全管理（官方接口支持时尝试调整/恢复，受篡改防护和企业策略限制）
- Windows 更新服务配置调整与恢复
- 电源模式、屏幕/睡眠/休眠时间、休眠、快速启动和此前电源计划恢复
- 默认输入法读取/设置、默认应用关联查看及 Windows 官方更改入口
- 图标缓存刷新、重建、重启 Explorer
- BAT 自动化工作流：模块化动作编辑、保存/打开、生成独立 BAT
- 环境变量入口，原有系统开关扩展为 19 项

三、首次测试的推荐顺序
A. 只读：系统概览、详细硬件、网络诊断、日志数据库、打印机服务、启动项扫描。
B. 低风险：屏幕颜色测试、生成 BAT 后用记事本进行鼠标/键盘测试。
C. 有权限且现场操作时再测试：网络配置、MAC、RDP、启动项、Windows 更新/防护、图标重建。

四、重要限制
- 本包在 Linux 生成环境完成了源文件结构检查、文本数据完整性检查，但没有 Windows 编译器，未完成 Windows 实机编译或测试。
- 很多 Windows 11 系统和驱动会忽略某些旧版设置；写入配置不等于实际生效，界面应以重新读取结果为准。
- Windows Defender 的篡改防护、企业域策略/MDM 不会被绕过；安全防护一键请求关闭不保证全部成功，维护后请手动核实恢复。
- 修改网卡、MAC、RDP 端口可能导致远程会话中断，请尽量现场操作。
- 文件关联遵循 Windows 10/11 官方用户确认流程，不会强行修改 UserChoice。
- DMP 仅列文件和关联事件；不提供 WinDbg 内核堆栈分析。
- 自动化 BAT 依赖目标窗口焦点、DPI、分辨率、Windows API 是否允许向目标窗口发送输入；无法控制安全桌面/UAC。
- 启动项不包含所有开机自启动机制，例如某些服务、MSIX、UWP、计划任务；请结合任务管理器及任务计划程序查看。
- 软件全部本地运行、不联网、不安装驱动；使用系统自带命令行、WMI、注册表和 Windows PowerShell。

五、保存位置
本地日志及配置变更记录：%LOCALAPPDATA%\ITDesktopToolkit
所有离线数据库：应用所在目录\Database
改动数据库 TSV 文件后，返回工具箱点击「重新加载数据库」即可。
TXT/TSV 使用 UTF-8 编码；切勿把硬件序列号或日志未经检查发送给无关人员。

编译失败时，把命令窗口从第一条 error 开始的文字截图发回来即可，不要重新安装系统。

如果运行后没有报错但是回车不起作用，请在流程里明确添加“激活窗口”步骤，指定正确窗口标题和进程；Windows 可能拒绝后台程序给其他窗口发送输入。
如果出现 FAILED 错误，请提供具体文字；仅凭“回车无法正常运行”不能断定是脚本执行失败还是窗口焦点问题。
