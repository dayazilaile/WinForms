# WinForms 环境准备

整个文件夹可单独复制到 U 盘或其他电脑使用，不依赖先编译工具箱。

## 怎么使用

1. 双击 **01_检测环境.bat**：显示系统、位数、.NET Release、Windows PowerShell 版本和待重启状态。仅检测，不安装、不写日志。
2. 需要补组件时，按 [安装包说明](Installers/README.md) 从微软下载对应的官方完整安装包，放进 **Installers** 子目录。旧版曾用“安装包”目录，新版请把已有的官方包移动到 Installers。
3. 右键 **02_安装缺少组件.bat**，以管理员身份运行；确认显示的组件后按 `Y`。每次只装一个组件；已具备推荐环境时直接跳过，不需要提权或运行安装器。
4. 安装器要求重启时自行重启，再检测。Win7 通常先补 .NET 4.8，再重新运行安装入口补 WMF 5.1。不要一次叠加安装、强制关机或把 ZIP 改名成 MSU。

完整保留两个 BAT、Environment.cmd 和 Installers 目录。只复制某一个 BAT 或直接在 ZIP 内运行会提示缺少引擎，请完整解压。默认软件功能和工具箱其他功能不受本助手调整影响。

## 为什么旧版两个入口都被拦

旧入口用 PowerShell `-File` 加载 Environment.ps1，Windows 默认 Restricted 执行策略会直接阻止它，尚未进入检测或安装逻辑。这个错误不代表 .NET 没有安装，也不能通过管理员身份自动解决。

新版不再包含或加载 PS1：主流程是可审阅的 BAT/CMD，使用 Windows PowerShell 自带的短命令读取信息、检查管理员角色、验证微软签名和写入便携日志；安装由官方 EXE / Windows WUSA 执行。

不读取脚本后动态执行，不编码/隐藏执行，不修改任何执行策略，不使用 Bypass，不解除下载标记，也不关闭安全软件。Restricted 的脚本文件限制与执行单个命令是不同的；若组织还限制 PowerShell 程序、命令、WMI 或安装器本身，仍需管理员按管理规范处理，本助手不会覆盖这些限制。

## 系统与组件

| 系统 | 处理方式 |
| --- | --- |
| Win7 | 必须 SP1。主程序最低 .NET 4.5，建议 4.8；自动化 BAT 需 Windows PowerShell 5.1。助手的检测命令按系统自带 PowerShell 2.0 编写 |
| Win10 / Win11 | 通常已有组件，以实际检测为准；已有 .NET 4.8/4.8.1 和 Windows PowerShell 5.1 不运行安装器。早期 Win10 需系统更新，不套用旧 WMF 包 |
| Win8.1 | 识别对应 x86/x64 WMF 包 |
| Server | 辅助识别 2008 R2 SP1、2012、2012 R2、2016 及以上 x64 桌面环境；安装 WMF 需自行核对服务器产品兼容性。冻结的 v0.5.20-Server 发布包不改动 |

本助手不联网下载组件，不处理 ARM/32 位 Server/缺少 WMI 或 Windows PowerShell 的精简系统。PowerShell 7 不替代 Windows PowerShell 5.1；环境更新也不会补出旧系统不存在的网络模块。

.NET 4.5～4.7 已达到主程序最低要求，升级 4.8 是建议。检测返回 0 表示达到主程序最低 .NET 与自动化 PowerShell 要求，不等于已完成所有 Windows 更新。待重启状态：0=未检出，1=需要重启，2=读取失败；要安装时后两者均先停止。

## 安装保护与日志

.NET EXE 必须通过有效的微软签名检查；MSU 由 WUSA 验证签名和适用系统。证书、时间、SP1、SHA-2、服务堆栈或其他更新不全时仍可能安装失败，不跳过签名校验。

不自提权、不自动重启。安装前必须能写入本文件夹 **Logs/environment-install.tsv**，失败就不启动安装器；结果日志失败时明确显示安装器实际返回码，不转存到 AppData/TEMP。记录时间/时区、主机名、MAC、IP、系统、账户、组件和结果；表头使用对应英文短名，字段缺失明确写 unread。.NET 详细日志也指定在本文件夹 Logs。

微软安装器、Windows 和安全产品自身仍可能在电脑上保存缓存、事件、安装日志，这些不是工具日志。删除本文件夹不等于卸载组件或清除系统记录。

退出码：0=达标/安装器成功/用户取消；5=检测不足或平台不支持；1=失败或被阻止；3010=要求自行重启。

云端执行了实际内联命令的模拟测试，没有真实安装组件。新增 Windows 专用回归会在受限子进程中先验证 PS1 被阻止，再运行两个 BAT；云环境没有 cmd.exe，因此该部分仍待 Windows CI/实机执行，不能宣称已完成 Win7/Server 安装认证。
